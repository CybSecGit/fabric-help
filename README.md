## 🌟 Overview

Fabric is a powerful command-line tool that leverages AI to analyze, generate, and manipulate text in various ways. It offers a wide range of patterns for tasks such as summarization, content creation, code analysis, and more. Here are some things that make using it a bit easier initially

## 📊 Pattern Statistics

**Total Patterns Documented**: 202 patterns (100% coverage)

### Pattern Categories:
- 🏛️ **Template Patterns (t_*)**: 15 patterns - Strategic frameworks and comprehensive analysis templates
- 📊 **Analysis Patterns**: 33 patterns - Evaluate, analyze, and assess various content types
- 📝 **Summarization Patterns**: 13 patterns - Create concise summaries of long content
- 🎨 **Creation Patterns**: 51 patterns - Generate new content from academic papers to security rules
- 🔍 **Extraction Patterns**: 38 patterns - Extract key insights, patterns, and data
- 🔧 **Improvement Patterns**: 4 patterns - Enhance writing quality and content
- 🏆 **Evaluation Patterns**: 8 patterns - Assess quality and rate content
- 🔄 **Transformation & Utility**: 7 patterns - Convert formats and provide utilities
- 🧩 **Miscellaneous Patterns**: 33 patterns - Specialized tasks and unique applications

## 🚀 Key Features

- 🧵 **Piping**: Chain patterns together for powerful workflows
- 🤖 **AI-Powered**: Leverages LLMs for intelligent text processing
- 🔗 **Composable**: Combine patterns for complex operations
- 📈 **Comprehensive**: 202 patterns covering diverse use cases

## 🛠️ Usage

To generate innovative pattern combination ideas:

1. Choose either the [Wiki](fabric-wiki.md) or [Cheatsheet](fabric-cheatsheet.md) based on your preference.
2. Feed the selected document into your preferred Large Language Model (LLM).
3. Ask the LLM to generate pattern combination ideas based on the provided information.
4. A couple of examples are provided in the [pattern-combinations](pattern-combinations/) directory.

This approach allows you to leverage AI to create unique and powerful combinations of Fabric patterns tailored to your specific needs.
